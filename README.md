# P's Card Play

A browser-based card game platform hosting 10 complete games.

## Games
- Blackjack
- Texas Hold'em
- Solitaire
- Memory Match
- War
- Go Fish
- Baccarat
- Crazy Eights
- Gin Rummy
- 5-Card Draw

## Stack
HTML · JavaScript · Tailwind CSS · Netlify
